# routr-video boundaries

| Situation | Use instead |
|-----------|-------------|
| CSS animation in live app | `routr-motion` |
| Landing page copy | `routr-marketing` |
| Build marketing page | `routr-frontend` |
| Unclear video vs design | Ask 2 questions max, then pick launch or remotion reference |

The launch and Remotion workflows live here — see [launch.md](./launch.md) and [remotion.md](./remotion.md).

## Precedence over self-declared entry points

The installed `hyperframes` skill may describe itself as the default for "any video request." That claim covers stack execution once HyperFrames is selected — it does not skip `routr-video`'s workflow selection (brag vs product-launch-video vs pr-to-video vs Remotion). Route here first; see [resolution.md](../../routr-catalog/references/resolution.md#stack-entry-points-vs-workflow-selectors).
